# Software Design, narrated

A personal companion for following [MIT 6.1040 Software Design (Fall 2026)](https://61040.github.io/fa26/) as a listener. Each lecture page embeds the official slides live from the course website and adds a narrative, margin notes (sources, industry connections, debates), self-check questions, and per-slide notes you can copy into a chat.

Slides © MIT 6.1040 staff; they are loaded from the course site, not stored here. Narration was written with Claude for personal study and is not affiliated with MIT.
